# Conceito artístico — Trilho das Estrelas (novembro)

**Imagem proposta:** `../imagens/CONCEITO_ARTISTICO_NOVEMBRO.png` (nova arte); o esboço de outubro pertence ao ZIP da milestone anterior e não integra este ZIP autónomo.

## Identidade visual
- **Tema:** corrida espacial entre estrelas e planetas, com destino num portal luminoso.
- **Paleta:** azul-noite e violeta para o espaço, turquesa e verde para bónus, vermelho/coral para recuo, dourado para chegada.
- **Elementos:** percurso de casas luminosas, estrelas, nebulosas, planeta com anéis, peões de três cores.
- **Legibilidade da GUI:** casas numeradas e cores distintas para avançar (+4), recuar (−4) e meta, acompanhadas de texto (não depender só de cor).
- **Aplicação:** arte usada como cabeçalho/atmosfera na interface; número das casas e posição dos peões são desenhados por componentes Swing para se manterem atualizados.

**Estado:** imagem conceitual, não substitui o tabuleiro funcional. A arte foi gerada com assistência de IA e deve ser validada e aceite pelo grupo. O produto final não utiliza recursos externos em tempo de execução.
